# FlowBridge Systems LLC — Launch Kit

## Application and delivery platform

The website is now sourced as an **ASP.NET Core 10** application, pinned to .NET SDK **10.0.401**. The static production package is generated from `src/FlowBridge.Web/wwwroot` only after the .NET build and tests succeed. The branch and deployment model is documented in [CI_CD_SETUP.md](CI_CD_SETUP.md).

## Use this kit in order

1. Read [LLC_SETUP_CHECKLIST.md](LLC_SETUP_CHECKLIST.md) and complete the legal and banking choices before taking client money.
2. Copy the profile and outreach text in [LINKEDIN_PROFILE_COPY.md](LINKEDIN_PROFILE_COPY.md) into LinkedIn.
3. Use [BUSINESS_MODEL.md](BUSINESS_MODEL.md) as the source of truth for offers, scope, pricing, and sales focus.
4. Configure the Odoo operating system from [AUTOMATION_RUNBOOK.md](AUTOMATION_RUNBOOK.md). Test each automation in a non-production database first.
5. Use [CLIENT_ASSETS.md](CLIENT_ASSETS.md) for fit calls, paid audits, proposals, and weekly client updates.
6. Open `dist/index.html` locally to use the launch dashboard, then replace the provisional website details after the LLC name, domain, and preferred contact channel are finalized.

## What is deliberately not automated here

No state filing, EIN application, bank account, insurance purchase, domain purchase, Odoo deployment, or LinkedIn publishing was performed. Each requires identity, payment, and/or account authority that only the business owner should provide. The checklists and workflow specifications reduce those tasks to a controlled sequence.
